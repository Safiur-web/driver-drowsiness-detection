# Driver Drowsiness Detection

This project detects if a driver is feeling sleepy using computer vision. It uses OpenCV and a deep learning model to monitor eye movement and alert when drowsiness is detected.

## 🔧 Features

- Real-time eye and face detection
- Drowsiness alert using sound
- OpenCV + Python based implementation

## 📦 Tech Stack

- Python
- OpenCV
- Haarcascade Classifiers
- Pygame (for sound)

## 🚀 How to Run

```bash
pip install -r requirements.txt
python drowsiness_detect.py
```
